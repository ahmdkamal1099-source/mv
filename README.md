# كورس التنفس الصناعي – د. كمال | Mechanical Ventilation Course

صفحة هبوط (Landing page) ثابتة بملف واحد `index.html`، بدون أي مكتبات أو build.

## النشر على GitHub Pages
1. أنشئ Repository جديد على GitHub (مثلا `mv-course`).
2. ارفع الملفات `index.html` و `README.md` و `.nojekyll`.
3. من **Settings → Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط Save.
4. بعد دقيقة تقريبا يظهر الرابط: `https://USERNAME.github.io/mv-course/`

## التعديل
- الأسعار: ابحث عن قسم `class="prices"` في `index.html`.
- روابط تيليجرام: ابحث عن `t.me`.
